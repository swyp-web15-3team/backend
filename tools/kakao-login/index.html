Kakao 로그인 테스트

백엔드의 Kakao 로그인 전체 흐름을 브라우저에서 확인합니다.

카카오 로그인 시작

대상 서버: http://localhost:8080

실행 준비

  1. Kakao Developers에서 앱의 카카오 로그인을 활성화하고 Redirect URI에 http://localhost:8080/auth/kakao/callback을 등록합니다.
  2. 백엔드 루트의 .env에 아래 값을 설정합니다. Client Secret을 사용하는 앱은 해당 값도 입력합니다. 키와 시크릿은 이 HTML에 넣지 않습니다.
KAKAO_LOGIN_ENABLED=true
KAKAO_CLIENT_ID=앱의_REST_API_키
KAKAO_CLIENT_SECRET=
KAKAO_REDIRECT_URI=http://localhost:8080/auth/kakao/callback
  1. 기존 DB 접속 설정과 유효한 JWT_SECRET을 준비하고 DB를 실행합니다. JWT_SECRET은 최소 32바이트 난수를 Base64로 인코딩한 값이어야 합니다.
  2. 저장소 루트에서 ./gradlew bootRun으로 백엔드를 실행합니다.
  3. 이 HTML 파일을 브라우저에서 직접 열고 로그인 버튼을 누릅니다. 별도 HTML 서버는 필요 없습니다.

결과 확인

카카오 로그인과 동의가 끝나면 백엔드 콜백 화면으로 이동합니다. 성공 응답의 accessToken, refreshToken, expiresIn을 확인하세요. 토큰은 콜백 화면에 표시되므로 응답을 공유하지 마세요.

다시 테스트하려면 이 페이지로 돌아와 로그인 버튼을 누르세요. 콜백 URL을 새로고침하면 이미 사용한 state가 거부되어 400 오류가 발생합니다.

  • 연결 실패: 백엔드 실행 여부와 포트를 확인합니다.
  • 404: KAKAO_LOGIN_ENABLED=true 적용 후 서버를 재시작했는지 확인합니다.
  • 400 / Invalid OAuth state: 로그인 버튼부터 다시 시작합니다. 로그인 시작 주소와 콜백 주소의 호스트를 동일하게 유지하세요. localhost와 127.0.0.1을 섞지 않습니다.
  • 카카오 설정 오류: REST API 키, Client Secret, 등록한 Redirect URI와 서버 설정을 확인합니다.

다른 호스트나 포트를 쓰면 HTML의 로그인 링크, 서버의 KAKAO_REDIRECT_URI, Kakao Developers에 등록한 Redirect URI를 함께 변경하세요.
